Pricing page sells unlimited API requests. Docs document rate limits.

Pricing page

Unlimited API requests

Unlimited API requests
cronitor.io/pricing

Product documentation

Rate limited, 429 on excess

The API has rate limits to ensure fair usage. If you exceed these limits, you'll receive a 429 Too Many Requests response.
cronitor.io/docs/api
Impact
The docs never publish the numbers, so a developer cannot size an integration before building it.
Check
A rate limit caps speed, not volume, so both can be true. One line on the pricing page would close it.

02mediumMissing informationmedium confidence

SSO guide names the plan requirement. It omits the $5 per user charge.

Pricing page

SSO costs $5 per user extra

SAML SSO (+$5/mo per user)
cronitor.io/pricing

Product documentation

Just subscribe to Business

Note: If the button is disabled, ensure your team is subscribed to the Business plan.
cronitor.io/docs/saml-sso
Impact
An admin who follows the guide upgrades to Business and meets the surcharge on the next invoice. On twenty seats that is $100 a month.
Check
The guide is not wrong, a Business subscription genuinely is required. Six more words would make it complete.

Definitions

Ambiguity: Both statements can be true, but a customer cannot tell what they get.

Missing information: Something that changes the deal, published somewhere the buyer will not look.
