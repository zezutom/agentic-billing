## 1. “Unlimited” is advertised, but a fair-use restriction is buried on another page

`medium impact` · `Ambiguity` · `high confidence`

Your commercial pages advertise unlimited API requests, while a separate page qualifies usage with a fair-use or acceptable-use restriction. A customer deciding on price never sees the qualifier; a customer who hits it experiences it as a broken promise.

**What your pricing says:** Unlimited API requests (no specific plan)
> Unlimited API requests
> — [Simple Pricing](https://cronitor.io/pricing)

**What another page says:** Usage is subject to a fair-use / acceptable-use restriction
> The API has rate limits to ensure fair usage.
> — [Cronitor API Docs](https://cronitor.io/docs/api)

*Worth knowing: Fair-use clauses are standard practice. The issue is placement and wording, not the existence of the clause.*
